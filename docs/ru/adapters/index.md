# Адаптеры

Подключите undevice к серверному приложению, чтобы определять устройство по заголовкам каждого запроса.

## Доступные адаптеры

Адаптеры входят в пакет `undevice` и поддерживают заголовки CDN, стандартные и пользовательские флаги с типизацией.

| Адаптер | Импорт | Результат |
| --- | --- | --- |
| [Express](/ru/adapters/express) | `undevice/express` | `res.locals.undevice` |
| [Fastify](/ru/adapters/fastify) | `undevice/fastify` | `request.undevice` |

## Другие фреймворки и SSR

API ядра принимает заголовки напрямую и подходит для других фреймворков без адаптера.
В руководстве [API ядра и SSR](/ru/guide/adapters) приведены примеры для Express и Fastify, Astro и обработчиков Fetch, а также рекомендации по гидратации.
