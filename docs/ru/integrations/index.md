# Интеграции

Подключите undevice к серверному приложению, чтобы определять устройство по заголовкам каждого запроса.

## Доступные адаптеры

| Интеграция | Импорт | Возможности |
| --- | --- | --- |
| [Express](/ru/integrations/express) | `undevice/express` | Middleware записывает результат в `res.locals.undevice`. Поддерживает заголовки CDN, стандартные и пользовательские флаги с типизацией. |

Адаптер Express входит в пакет `undevice`.

## Другие фреймворки и SSR

API ядра принимает заголовки напрямую и подходит для других фреймворков без адаптера.
В руководстве [API ядра и SSR](/ru/guide/integrations) приведены примеры для Express и Fastify, Astro и обработчиков Fetch, а также рекомендации по гидратации.
