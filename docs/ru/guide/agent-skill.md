# Скилл для агента

Скилл помогает coding-агенту использовать undevice, настраивать расширения и подключать библиотеку к обработчикам запросов.

```sh
npx skills add teplostanski/undevice --skill undevice
```

[Исходный скилл](https://github.com/teplostanski/undevice/tree/main/skills/undevice).

Для загрузки документации агентом доступны [llms.txt](/llms.txt) и [llms-full.txt](/llms-full.txt).
