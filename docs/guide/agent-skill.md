# Agent skill

The skill helps a coding agent use undevice, configure extensions, and connect detection to request handlers.

```sh
npx skills add teplostanski/undevice --skill undevice
```

For Express middleware and route types, use [undevice-express](https://github.com/teplostanski/undevice/tree/main/skills/undevice-express).

```sh
npx skills add teplostanski/undevice --skill undevice-express
```

[Skill source](https://github.com/teplostanski/undevice/tree/main/skills/undevice).

Machine-readable documentation is available as [llms.txt](/llms.txt) and [llms-full.txt](/llms-full.txt).
