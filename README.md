# undevice

Runtime-agnostic user-agent device detector.

> Work in progress. The package is not published yet.

## Goals

- Detect device, operating system, browser, and crawlers.
- Run in Node.js, browsers, and edge runtimes.
- Keep the core independent from frameworks and runtime-specific APIs.
- Provide separate framework adapters in the future.
